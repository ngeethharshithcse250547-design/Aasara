## Important reconciliation note

The current NSFDC FAQ describes a network of **102 partners**. The eight downloadable category registers accessed on 9 September 2026 enumerate **91 named organisations** (38 SCA + 11 PSB + 26 RRB + 7 NBFC-MFI + 2 Co-operative Bank + 3 Other/SIDBI + 2 SFB + 2 Cooperative Society). This pack preserves both official facts and flags the difference for directory refresh. It does not create 11 assumed records.

## Rules for using this research in the prototype

1. Cite the original official NSFDC page or register in the UI/admin record, not this summary alone.
2. Label scheme outputs as potential matches until an authorised agency validates the application.
3. Use the exact source date/last-verified date on every hard-coded rule.
4. Do not state a named partner's fund availability, utilisation, overdue status, NPA, approval rate or routing eligibility without a timely authorised source.
5. If demo partner status is needed, prefix it **SIMULATED - DEMO ONLY** and store it separately from verified records.
6. Refresh partner registers before any public demo or final submission, because partner agreements and addresses can change.
